# INTOK Academy

موقع استشارات تعليمية متعدد اللغات مبني على Laravel 12. واجهاته العامة بالعربية والإنجليزية والإيطالية، ولوحة الإدارة مخصصة ومكتوبة بـ Blade مع أصول Vite عند تثبيت تبعيات الواجهة.

## المتطلبات

- PHP 8.2 أو أحدث مع امتداد GD، وMySQL 8.
- Composer.
- Node.js 20 أو أحدث وnpm.

## التشغيل المحلي

```powershell
composer install
Copy-Item .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
```

أنشئ حساب المدير من الأمر التفاعلي بعد تجهيز قاعدة البيانات، ثم ثبّت تبعيات الواجهة:

```powershell
npm install
php artisan intok:admin:create admin@example.com
composer dev
```

تستخدم الصفحات ملف CSS محليًا كمسار بديل عندما لا يكون Vite manifest موجودًا. للتطوير الكامل، شغّل `composer dev`؛ يبدأ خادم Laravel وVite وReverb وعامل الطوابير. يرسل Reverb تنبيهات الاستفسارات الجديدة مباشرة إلى لوحة الإدارة، وتحتاج مصادقة البث إلى جلسة دخول. اضبط مفاتيح Reverb وإعدادات البريد في `.env` قبل اختبار الإرسال أو النشر.

## إعداد مدير النظام

أنشئ حساب المدير تفاعليًا؛ سيطلب الأمر الاسم وكلمة المرور دون تخزينها في الشيفرة:

```powershell
php artisan intok:admin:create admin@example.com
```

ثم افتح `/admin/login`. لا يوجد حساب تجريبي أو كلمة مرور افتراضية.

## المسارات الأساسية

- الموقع العام: `/ar` و`/en` و`/it`.
- قائمة الخدمات: `/{locale}/services`، وتفاصيل كل خدمة لها slug خاص باللغة.
- إرسال الاستفسار: `/{locale}/contact`.
- تسجيل العميل وحجز الاستشارة: `/{locale}/register` و`/{locale}/consultation`.
- قصص النجاح: `/{locale}/testimonials`، والصفحات المنشورة من الإدارة: `/{locale}/p/{slug}`.
- تسجيل الدخول: `/admin/login`.
- لوحة الإدارة والتنبيهات الفورية: `/admin`.
- إدارة الخدمات والفريق والاستفسارات والحجوزات والتسجيلات وإعدادات الموقع ضمن `/admin`.

## قاعدة البيانات

يحتوي المشروع على جداول المستخدمين والصلاحيات والخدمات وأعضاء الفريق والاستفسارات وإعدادات الموقع. المحتوى المترجم محفوظ بصيغة JSON، مع أعمدة slugs مفهرسة لكل لغة لتسهيل الروابط والبحث. إعداد `.env.example` يستخدم MySQL؛ يمكن استخدام SQLite محليًا وتحديث إعداد قاعدة البيانات في `.env` للنشر.

## حالة دمج مكتبات خارجية

يستخدم المشروع مصادقة جلسات Laravel مع صفحات Inertia وReact مخصصة، وSpatie Permission للأدوار، وLaravel Reverb مع Echo للتنبيهات الفورية. لوحة الإدارة مبنية على تخطيط InApp المرفق مع Bootstrap وTabler، مع RTL وربط الإحصاءات والتنبيهات ببيانات Laravel. الترجمة مخزنة في أعمدة JSON مع casts صريحة بدل إضافة مكتبة ترجمات غير لازمة لهذا النموذج. تُحوّل صور الخدمات والفريق إلى WebP بواسطة Intervention Image وتُخزن على قرص Laravel العام.
